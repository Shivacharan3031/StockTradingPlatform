# Stock Trading Platform

A Java-based Stock Trading Platform that simulates basic stock market activities such as viewing stock prices, buying stocks, selling stocks, and tracking portfolio performance.

## Features

* Display available stocks and their prices
* Buy stocks using available balance
* Sell stocks from the portfolio
* Track user balance
* Manage stock holdings
* Calculate portfolio value
* View transaction details
* Demonstrate object-oriented programming concepts

## Technologies Used

* Java
* Object-Oriented Programming
* Collections
* Exception Handling
* File Handling, if implemented

## OOP Concepts Used

* **Classes and Objects**
* **Encapsulation**
* **Inheritance**
* **Polymorphism**
* **Abstraction**
